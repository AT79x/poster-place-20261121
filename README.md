A program that draws one travel poster for **VELDARIS**, a place that isn't there, as a 1024×1024 PNG to `/output/entry.png`. Pure Python 3 standard library, deterministic, no network.

Veldaris is a cliff town above a still lagoon where the sky falls in ribbons of green light: the Starlight Observatory keeps watch from the headland, its beam rising into the aurora; below it, terraced houses light their windows at dusk, a crescent moon hangs over the water, and a small lantern boat crosses the lagoon. The name is set large across the bottom in a hand-built stroke font, so the eye travels from the name to the tower and on to the horizon.

## Run it

```sh
python3 main.py
```

Writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Two runs write byte-identical PNGs.
